# Skydash Node.js Dashboard

A simple Node.js application created by converting the **Skydash Free Admin Template** into an **Express.js + EJS** project.

## Purpose

The project was built to:

- Convert a static admin template into a Node.js application
- Handle page routing using Express.js
- Render pages dynamically with EJS
